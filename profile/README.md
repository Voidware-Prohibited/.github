### Organizational Ethos
- Empower Individuals and small independent Studios with AAA Feature Parity or better.
- Promote and Advance Electronic Freedom the Free and Open Source Software Movement.
- Utilize the latest Technologies and Methodologies.
- Maintain Modular, Configurable and Data-oriented Designs.
- Adhere to and Facilitate adherence to Coding Standards and Style Guides.
- Encourage and Facilitate the use of Versioning Systems and CI/CD.
- Performance and Optimization by Design.
- No Monetization or Crypto.
- Humanity First.
- Do Cool Stuff.

### Featured Projects

#### Unreal Engine
- [Chrome Ronin](https://codeberg.org/Voidware-Prohibited/Chrome-Ronin)
- [Target Vector](https://codeberg.org/Voidware-Prohibited/TargetVector): Rewrite the Rules of Engagement.
    - [Target Vector Plugins](https://codeberg.org/Voidware-Prohibited/TargetVectorPlugins): List of all Target Vector plugins.
    - [Ricochet](https://codeberg.org/Voidware-Prohibited/Ricochet): Realistic, GAS-based, Network-predicted, Ballistics for UE5.
    - [Aurora](https://codeberg.org/Voidware-Prohibited/Chronos): Serialize, Initialize, Deserialize and Import Server Maps to and from JSON or PostgreSQL Database.
    - [Axos](https://codeberg.org/Voidware-Prohibited/Chronos): Replicated True North Game State Component.
    - [Chronos](https://codeberg.org/Voidware-Prohibited/Chronos): Calendar System for Unreal Engine.
    - [Clima](https://codeberg.org/Voidware-Prohibited/Clima): A Parametric, Multiplayer Weather system with Micro-Climates for UE5 utilizing GAS and World Partition System.
    - [Travos](https://codeberg.org/Voidware-Prohibited/Travos): Replicated Footstep System with World Partition support.
- [ALSXT](https://codeberg.org/Voidware-Prohibited/ALSXT): Cutting-Edge, Data-oriented, Modular, GAS-based, Procedural Character System built on ALS-Refactored.
    - [ALSXT Dash Ability](https://codeberg.org/Voidware-Prohibited/AlsxtDashAbility): GAS-based Dash Ability Modular Game Feature for ALSXT.
- [ShowNight Live](https://codeberg.org/Voidware-Prohibited/ShowNightLive): Immersive Live Performance Framework with Remote Control, MIDI, OSC, Equipment Signal Mapping, LiveLink and VR support.
